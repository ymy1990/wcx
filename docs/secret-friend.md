# 密友功能修复说明

当前本地维护分支已合并至 WCX v294，入口沿用「功能 → 密友功能」，保留现有菜单布局。下方保留早期 v287 的发布记录。

## 本次修复

- 统一标题多击与长按手势处理，减少微信标题双击行为及标题视图重建对触发的影响。
- 临时显示密友后，进入对话继续保持显示；退出任意对话回到主页时，由「离开对话恢复隐藏」控制恢复。
- 「离开主页/切走微信恢复隐藏」独立控制离开主页、按 HOME 或微信转入后台后的恢复。两个恢复开关可以分别使用。
- 已处于隐藏状态时跳过重复恢复提示；操作提示缩短为约 1 秒。
- 加粗与圆点根据密友未读消息显示，只在打开对应密友对话后清除；返回主页或打开其他对话保留提示。
- 「密友显示状态提示」默认开启，临时显示密友时在原未读圆点的位置显示绿点，恢复隐藏后消失；红点和绿点共用大小。绿点只表示显示状态，不清除密友未读记录，且不受「圆点提示」开关控制。
- 保留定时显示/隐藏和自动拒绝音视频通话，并提供独立开关。
- 保留密友名单及相关配置，兼容原组合恢复设置和旧标题多击设置；隐藏处理不删除会话记录，也不主动清空原生未读数。
- 修正可选 DEX 目标未解析时的占位方法识别，避免错误安装 Hook。

## 当前本地构建

在维护分支运行 `./Sync-WcxLocal.ps1 -BuildOnly`，生成 `v294-wcxlc-local` 安装包并递增版本代码。继续使用本地同一签名，升级后重启微信。源码和安装包中的新增功能默认只保存在本地，发布需另行执行。

## v287 构建与发布记录

本次发布为 `standardDebug`、`arm64-v8a` 测试包，使用此前本地密友包的同一签名。
版本名为 `v287-wcxlc-secretfix`，版本号为 `3545137`。源码中的上游 v287 元数据保留，发布构建通过 Gradle 属性指定版本：

```bash
./gradlew :app:assembleStandardDebug \
  -PwcxlcVersionCode=3545137 \
  -PwcxlcVersionName=v287-wcxlc-secretfix
```

构建环境需要 JDK 21，以及项目依赖使用的 JDK 17 工具链、Android SDK 和项目原生库。
签名通过 `WEKIT_KEYSTORE_FILE`、`WEKIT_KEYSTORE_PASSWORD`、`WEKIT_KEY_ALIAS`、`WEKIT_KEY_PASSWORD` 环境变量提供。
私有签名文件和密码不属于源码或发布附件。

本次已进行 Kotlin/Java 编译、APK 打包、签名校验和功能注册表检查。当前 v287 包未做实机回归测试。
升级后重启微信使 Hook 生效。签名相同的此前本地密友包可覆盖安装；其他签名的包无法直接覆盖。

本次 GitHub 发布上传本地编译的同签名 APK，提交采用仓库已有的 `[skip ci]` 机制，避免 CI 自动生成另一签名的发行包。

## 后续同步上游

已发布的 v287 密友修复保存在 fork 的 `master` 中，后续本地更新保存在维护分支。同步新版本时，将上游提交合并进维护分支，保留这些改动：

```bash
git remote add upstream https://github.com/Johnny520/wcx.git
git fetch upstream
git merge upstream/master
```

已有 `upstream` 远程时从 `git fetch` 开始。若发生冲突，结合新版微信接口保留或调整密友实现，完成编译后再做实机验证。
后续自定义包继续使用同一签名，并递增 `wcxlcVersionCode`，使覆盖安装可持续使用。
